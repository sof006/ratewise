# Libraries bundled in the AppImage, from Debian 10 (glibc 2.28).

# The binary links libfontconfig; winit and Slint dlopen the X11, xkbcommon and
# Wayland ones (ldd doesn't show those). AppRun uses a bundled copy only when the
# host doesn't have that library, so a desktop's own libraries, which its GPU driver
# was built against, always win. The GPU stack (libGL, libEGL, …) always comes from
# the host.
